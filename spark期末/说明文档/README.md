# Spark股票大数据分析系统

## 1. 概述

### 1.1 实验环境简述

- **Spark版本**: PySpark 3.4.0+
- **Python版本**: 3.10.1+
- **数据库**: MySQL 8.0+
- **开发工具**: PyCharm / VSCode / IDEA

### 1.2 项目简介

本项目是一个基于Spark的股票大数据分析系统，从东方财富网爬取股票数据，经过数据清洗、预处理后，使用Spark进行多维度分析（趋势分析、波动性分析、量价关系等），最终将分析结果存储到MySQL数据库中。

### 2.1 需求分析阶段

#### 项目背景

随着中国资本市场的快速发展，股票市场数据呈现爆炸式增长。投资者面临着海量数据的挑战，如何从大量的股票数据中提取有价值的信息，成为投资决策的关键。

本项目旨在通过大数据技术，构建一个集数据采集、存储、分析、可视化于一体的股票大数据分析与管理系统，帮助投资者了解市场动态、优化投资策略、提升投资收益。

#### 项目目标

- **数据采集自动化**：从东方财富网自动爬取股票行情数据
- **数据存储规范化**：建立统一的MySQL数据存储架构
- **数据分析智能化**：利用Spark进行多维度技术分析
- **结果可视化直观化**：通过图表展示分析结果
- **管理系统化**：提供完整的数据管理流程

### 2.2 数据采集阶段

**数据来源**: 东方财富网 (http://quote.eastmoney.com/)

**采集内容**:
1. 股票基本信息（代码、名称）
2. 历史行情数据（开盘价、收盘价、最高价、最低价）
3. 交易数据（成交量、成交额）
4. 时间序列数据（日期、星期、月份）

**⚠️ 注意**: 爬虫模块 `spider/stock_spider.py` 需要根据实际情况手动补充和完善。

### 2.3 数据处理阶段

#### 数据清洗流程

```python
原始数据 → 去重 → 处理缺失值 → 处理异常值 → 类型转换 → 删除无效数据 → 特征工程
```

#### 核心处理步骤

1. **数据去重**: 删除完全重复的记录
2. **缺失值处理**: 数值列用中位数填充，日期列删除缺失行
3. **异常值处理**: 使用IQR方法修正异常值
4. **数据类型转换**: 确保日期、数值列类型正确
5. **特征工程**: 计算涨跌幅、价格波动、振幅、移动平均线等

### 2.4 数据分析阶段

#### 分析架构

```
┌─────────────────────────────────────────┐
│         数据采集层 (爬虫)                │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│       数据预处理层 (Pandas)              │
│  清洗 → 转换 → 特征工程                  │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│      Spark分析层 (PySpark)               │
│  ┌──────────┐ ┌──────────┐            │
│  │趋势分析  │ │波动性分析│            │
│  └──────────┘ └──────────┘            │
│  ┌──────────┐ ┌──────────┐            │
│  │量价分析  │ │排名分析  │            │
│  └──────────┘ └──────────┘            │
└──────────────┬──────────────────────────┘
               ↓
┌─────────────────────────────────────────┐
│      数据存储层 (MySQL)                  │
└─────────────────────────────────────────┘
```

#### 分析模块

1. **基础统计分析**: 记录数、股票数量、价格统计
2. **趋势分析**: MA5/MA10/MA20移动平均线、价格动量
3. **波动性分析**: 日收益率、年化波动率、风险指标
4. **量价关系分析**: 成交量与价格的相关性
5. **股票排名**: 按涨跌幅、成交量等指标排名

## 6. 实验结论

### 6.1 遇到的问题及解决方式

#### 问题1: Spark环境配置

**问题描述**: PySpark运行时提示找不到Spark环境

**解决方案**:
1. 下载并安装Spark
2. 设置环境变量 `SPARK_HOME`
3. 确保Java版本兼容

#### 问题2: 数据库连接失败

**问题描述**: 无法连接到MySQL数据库

**解决方案**:
1. 检查MySQL服务是否启动
2. 验证用户名密码是否正确
3. 确认数据库权限配置

#### 问题3: 爬虫数据获取失败

**问题描述**: 东方财富网反爬机制导致请求被拒绝

**解决方案**:
1. 添加合理的请求头（User-Agent）
2. 设置随机延迟避免频繁请求
3. 考虑使用代理IP池
4. ⚠️ 需要手动完善爬虫逻辑

#### 问题4: 内存不足

**问题描述**: Spark处理大数据时OOM

**解决方案**:
1. 调整Spark内存配置
2. 增加分区数
3. 使用persist()缓存常用数据
